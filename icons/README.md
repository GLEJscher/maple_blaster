# 아이콘 파일

넥슨 게임 아이콘(32px 안팎의 PNG)입니다. 파일 이름은 `index.html`과 `Skills.py`의 변수 이름과 같게 지었습니다 (예: `MF_LVL` → `mf_lvl.png`, `NOBLE_CRIT` → `noble_crit.png`).
링크 스킬은 코드에 영문 변수가 없어서 코드의 키(`데슬`)를 로마자로 옮겼습니다 (`link_deseul.png`).

화면에 나오는 아이콘과 파일의 연결은 `index.html`의 `LOCAL_ICON`에 있고, 여기에 없는 아이콘은 `ICON_DEFAULT`의 넥슨 서버 주소를 씁니다.
넥슨 코드는 넥슨 서버 주소(`https://open.api.nexon.com/static/maplestory/skill/icon/<코드>`)와 대조할 때 쓰세요. 아이템 도핑 아이콘은 스킬 API에 없어서 코드가 없습니다.
