# maple_blaster

메이플스토리 블래스터(블래) DPM 시뮬레이터입니다. 이 문서는 **사용자가 직접 바꿀 수 있는 입력값**만 설명합니다.

- `Skills.py`와 `Skills.ipynb`는 같은 내용의 파일입니다. (ipynb를 py로 변환한 것)
- 입력값은 `Skills.py`(또는 `Skills.ipynb`)의 맨 위, `아래 코드 수정X` 구분선 **위쪽**에 모여 있습니다.
- 구분선 아래의 코드(스킬 정의, 이벤트 엔진, 규칙)는 수정하지 않는 것을 전제로 합니다.
- 캐릭터 스펙은 `Skills` 파일의 `base_spec`에 있는 `CharaInfo(...)` 값을 직접 수정해서 입력합니다. (`CharaInfo` 클래스 자체는 `Attribute.py`에 정의되어 있음)
- 값을 바꾼 뒤에는 **입력 셀부터 아래로 다시 실행**해야 반영됩니다. (ipynb 기준)
- 주석에 `임시값`이라고 적힌 항목은 인게임에서 측정하지 못해 가정한 값입니다. 측정하면 바꿔 주세요.

---

## 1. 캐릭터 스펙

### `base_spec` (`CharaInfo`)
`Skills` 파일의 `base_spec = CharaInfo(...)`에 있는 값을 자신의 스펙으로 바꿔 입력합니다. 스탯창 기준 스펙이며, **자버프를 모두 사용하고 헤카테를 소환한 비전투 스탯창** 기준으로 적습니다.

| 필드 | 의미 |
|---|---|
| `level` | 캐릭터 레벨 |
| `mainStat`, `mainStatp`, `fixedMainStat` | 주스탯 기본 수치, 주스탯 % 수치, % 미적용 주스탯 |
| `subStat`, `subStatp`, `fixedSubStat` | 부스탯 기본 수치, 부스탯 % 수치, % 미적용 부스탯 |
| `attack`, `attackp` | 공격력 기본 수치, 공격력 % 수치 |
| `damage` | 데미지 % |
| `bossDamage` | 보스 데미지 % |
| `armorIgnore` | 방어율 무시 % (다른 값과 곱연산으로 합쳐짐) |
| `finalDamage` | 최종 데미지 % (곱연산) |
| `critDamage` | 크리티컬 데미지 % |
| `attribResist` | 속성 내성 무시 % |
| `buffDuration` | 버프 지속시간 % (벞지) |
| `cooldown` | 재사용 대기시간 감소(초) |

- 링크 스킬 중 **데슬, 데벤져, 레테, 키네시스, 제논**의 효과는 이미 스탯창 숫자에 들어 있다고 보고 `base_spec`에 그대로 적습니다. 나머지 링크는 코드가 `LINK_ON`/`LINK_LVL`에 따라 더합니다.
- 컨티뉴어스 링, 리스트레인트 링, 메여축, 리버티, 엔버 링크는 `base_spec`에 넣지 않습니다. 코드가 버프로 따로 적용합니다.

### `abnormal_status_damage`
상태이상 추가 데미지(상추뎀)입니다. **카데나 링크의 상추뎀은 제외**하고 적습니다. 카데나 링크의 상추뎀은 `LINK_ON`/`LINK_LVL`에서 따로 더해집니다.

### `union_effect`
유니온 효과를 기대값으로 환산해 적습니다. (예: 20% 확률로 데미지 +20% → `damage=4`)

## 5. 링크 스킬

### `LINK_ON`
링크별 사용 여부입니다. 12개 링크: `데슬`, `데벤져`, `카데나`, `레테`, `키네시스`, `제논`, `아크`, `엔버`, `모도`, `모법`, `일리움`, `카인`. 기본값은 `카인`만 `False`입니다. (카인 링크의 적중 횟수 규칙을 확인하는 중이라 꺼 둔 상태)

### `LINK_LVL`
링크별 레벨입니다. **게임에서 링크 레벨을 올렸다면 이 숫자만 바꾸면 됩니다.** 레벨별 효과는 코드의 `LINK_TABLES`에서 가져옵니다.

| 링크 | 입력 가능한 레벨 | 기본값 |
|---|---|---|
| 데슬, 데벤져, 레테, 키네시스, 제논 | 2, 3 | 2, 2, 2, 3, 2 |
| 카데나, 아크, 일리움 | 2, 3 | 2, 2, 2 |
| 엔버 | 2, 3 | 3 |
| 모도 | 6~9 | 6 |
| 모법 | 6~9 | 6 |
| 카인 | 2, 3 | 2 |

**주의: 데슬, 데벤져, 레테, 키네시스, 제논**
- 이 5개는 효과가 이미 `base_spec` 숫자에 들어 있습니다. 그래서 `LINK_LVL`은 "**스탯창에 반영된 내 실제 레벨**"을 뜻합니다.
- OFF로 하면 그 레벨의 효과를 `base_spec`에서 뺍니다.
- 레벨을 올렸다면 `base_spec`의 스탯 숫자도 새 스탯창 값으로 옮겨 적고, `LINK_LVL`도 같이 맞춰야 합니다.

**링크별 동작 요약**
- `카데나`, `아크`, `일리움`, `모법`: 전투 중 항상 켜져 있다고 보고 스펙에 더합니다. 모법은 약점 3중첩이 항상 유지된다고 봅니다. 카데나는 몬스터에 상태이상이 항상 걸려 있다고 봅니다.
- `엔버`: 액티브 스킬입니다. 버프 시퀀스에서 사용하고(준극딜에서도 사용), 지속 10초, 쿨 60초이며 벞지가 적용됩니다. OFF로 해도 준극딜은 인팬트리 → 버브 순서로 진행합니다.
- `모도`: 10초 지속. 첫 공격에서 발동하고, 쿨(20초)이 끝난 뒤 첫 타격에서 다시 발동합니다.
- `카인`: 20초 지속, 재발동 40초. 발동 조건은 아래 `KAIN_*`로 정합니다.
- 모도, 카인(그리고 일격필살)은 쿨감과 벞지의 영향을 받지 않습니다. 링크 중 벞지가 적용되는 것은 엔버뿐입니다.

### `KAIN_HITS_PER_PREP`, `KAIN_PREP_NEED`
카인 링크 발동 조건입니다. 공격 `KAIN_HITS_PER_PREP`번 적중 = 사전 준비 1번, 사전 준비 `KAIN_PREP_NEED`번이면 발동합니다. 기본값은 5, 5 (총 25번). 공격 스킬 1회 발동을 적중 1번으로 셉니다.

## 9. `run_bunker_maxi(...)` 인자

최종 실행 함수입니다. 위 전역 변수가 기본값이고, 인자로 **그 실행에서만** 덮어쓸 수 있습니다.

```python
state = run_bunker_maxi(spec, duration=60, buff_delay=BUFF_DELAY, breaker=True, vulkan=True, afterimage=True,
                    infantry=True, aura=True, order=None, hecate_on=True,
                    extra_buffs=True, conti_on=None, restraint_on=None, reuse=True, link_on=None, fatal_on=True)
```

| 인자 | 의미 | 기본값 |
|---|---|---|
| `spec` | 사용할 스펙 (`CharaInfo`) | 필수 |
| `duration` | 시뮬레이션 시간(초) | 60 |
| `buff_delay` | 버프 1개당 딜레이 | `BUFF_DELAY` |
| `order` | t=0 오프닝 순서. 주면 아래 `breaker`/`vulkan`/`infantry` 옵션 대신 이 순서를 사용 | `None` |
| `breaker`, `vulkan`, `infantry` | 오프닝에서 버브, 발칸, 인팬트리 사용 여부 (`order`가 없을 때만) | `True` |
| `afterimage` | 애프터쇼크 버프 사용 여부 | `True` |
| `aura` | 오라 웨폰 사용 여부 | `True` |
| `hecate_on` | 솔 헤카테(스틱스, 플레게톤 포함) 사용 여부 | `True` |
| `extra_buffs` | 메여축, 리버티, 엔버 링크 사용 여부 | `True` |
| `conti_on`, `restraint_on` | 시드링 ON/OFF (`None`이면 `SEED_CONTI`, `SEED_RESTRAINT`) | `None` |
| `link_on` | 링크 ON/OFF를 일부만 바꿈. 예: `link_on={"모도": False}`. 주면 `spec` 인자는 무시하고 `base_spec_no_link`에서 링크를 다시 계산함 | `None` |
| `fatal_on` | 일격필살 버프 사용 여부 | `True` |
| `reuse` | `True`면 쿨타임이 돌 때마다 극딜/준극딜을 반복. `False`면 반복 규칙 없이 기본 규칙(`RULES_MAXI`)을 사용 | `True` |

## 10. 결과 확인

실행 결과는 `state.log`에 `(t, 스킬 이름, 데미지)` 형태로 쌓이고, 아래처럼 DataFrame으로 볼 수 있습니다.

```python
dframe = pd.DataFrame(state.log, columns=["t", "skill", "damage"])
```

### 예시: 총합 데미지 확인

```python
total_damage = dframe["damage"].sum()
print(f"총합 데미지: {total_damage:,.0f}")
print(f"{SIM_TIME}초 동안의 DPM: {total_damage / SIM_TIME * 60:,.0f}")
```

### 예시: 스킬별 딜 점유율 확인

```python
by_skill = dframe.groupby("skill")["damage"].agg(["sum", "count"])
by_skill.columns = ["총 데미지", "사용 횟수"]
by_skill["점유율(%)"] = by_skill["총 데미지"] / by_skill["총 데미지"].sum() * 100
by_skill = by_skill.sort_values("총 데미지", ascending=False)
print(by_skill.round({"점유율(%)": 2}))
```

`사용 횟수`는 로그에 찍힌 행 수(공격 발동 횟수)이고, 점유율의 합은 100%입니다.
